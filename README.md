# fstack

Fernando's stack of agent skills for Claude Code: the things I like, do and use, each skill made for one specific job.

The name follows two other personal stacks:

- [pstack](https://github.com/poteto): Lauren Tan's skills.
- [tstack](https://github.com/t3dotgg): Theo Browne's skills.

Use them, fork them, ignore them.

## How to use a skill

Claude Code loads skills from `~/.claude/skills`. Copy a folder from `skills/` there, or clone this repo and run:

```bash
bash scripts/link.sh
```

It links every skill in `skills/` into `~/.claude/skills`, so the skill loads in every session and the text stays in one copy. It never replaces a folder that is already there with the same name; it reports it as a conflict.
